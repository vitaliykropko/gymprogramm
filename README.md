# 🏋️ Мобильное фитнес веб-приложение (PWA)

Готовое автономное мобильное веб-приложение для тренировок с прогрессией весов, трекером подходов, таймером отдыха и поддержкой 2 аккаунтов.

## 📱 Как установить на телефон (iPhone / Android)

Приложение работает как PWA (Progressive Web App):
1. Откройте сайт в браузере Safari (на iOS) или Chrome (на Android).
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой на iPhone) или три точки в углу (на Android).
3. Выберите пункт **«На экран Домой»** («Добавить на главный экран»).
4. На рабочем столе телефона появится полноценная иконка приложения. Оно будет запускаться во весь экран без рамок браузера и сохранять весь прогресс локально.

## 🚀 Как выложить на GitHub Pages (Бесплатно за 1 минуту)

1. Создайте бесплатный репозиторий на [GitHub.com](https://github.com) (например, workout-tracker).
2. Загрузите в него файлы из этой папки (index.html и ilya_workout_plan.html).
3. В репозитории откройте **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** (или master) / root (/)
   - Нажмите **Save**.
5. Через 30 секунд появится ваша личная ссылка вида:
   https://ВАШ_НИК.github.io/workout-tracker/
   Откройте эту ссылку на телефоне!

## ⭐️ Возможности приложения

- **2 независимых аккаунта:** мгновенное переключение в шапке (Илья / Атлет 2) с отдельной историей и рекордами.
- **Интерактивный трекер:** удобные степперы [-] [+] для весов и повторений, фиксация подходов ✓.
- **Плавающий таймер отдыха:** автозапуск при завершении подхода, звуковой сигнал и виброотклик.
- **GIF-анимации техники:** все 24 упражнения с плавными зацикленными видео без сторонней рекламы.
- **Калькулятор 1ПМ и весов:** автоматический расчёт одноповторного максимума (Epley/Brzycki) и подбор весов под зоны гипертрофии и силы.
- **Умная прогрессия:** подсказки «Добавить +2.5 кг», если все подходы закрыты по верхней границе.
- **Экспорт и импорт:** сохранение резервной копии базы в файл JSON в 1 клик.
